
# Práctica 1 — Programación Web Avanzada

**Universidad Bolivariana del Ecuador (UBE)**  
**Carrera:** Ingeniería en Sistemas Inteligentes  
**Organización:** Team-Evorion

## Descripción

Proyecto académico grupal correspondiente a la Unidad 1: Fundamentos de Programación Web.

Su objetivo es aplicar conocimientos de HTML5, CSS3 y principios de diseño responsivo mediante el desarrollo de dos páginas web.

## Ejercicios desarrollados

### Ejercicio 1 — Currículum Vitae

Página web que presenta un currículum profesional con información académica, habilidades, experiencia y proyectos.

### Ejercicio 2 — TechSolutions UBE

Sitio web empresarial ficticio que presenta servicios tecnológicos, portafolio, planes, testimonios, recursos, preguntas frecuentes, noticias y contacto.

Incluye navegación entre secciones, diseño responsivo y un formulario de demostración.

## Tecnologías utilizadas

HTML5, CSS3, JavaScript básico, CSS Grid, Flexbox y Media Queries.
